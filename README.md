# Moe-Kyaw-Aung-Portfolio V59

**Android Senior Developer** | 12+ Years Experience

A modern, terminal-style portfolio website built with HTML, Tailwind CSS, and vanilla JavaScript. Fully responsive and available as a Progressive Web App (PWA).

## 🚀 Features

- Terminal / Hacker aesthetic with monospace fonts
- Interactive particle hero background
- Fully responsive (mobile-first)
- Dark / Light mode toggle
- Contact form with validation
- PWA support (Installable)
- Smooth animations & scroll effects
- GitHub, Lovable WPA, and Email collections
- Back-to-top button + Sticky CTA
